## Not used (licensing / format)

- **Meshtint "100 Eggs Pack"** — a paid asset ($13.90); not included.
- **Hooray4Brains Forest pack** — free to use, but itch.io blocks scripted
  downloads. The author's shared Drive folder contains only Blender `.blend`
  **source** files (no `.glb`), which Godot cannot import without an
  installed Blender. To use them: export to glTF in Blender (or drop the pack's
  `.glb` files into `assets/models/`) and add them to `ModelLibrary` groups.

## Procedural assets

Everything else — characters, UI, music, ambience, and sound effects — is
generated by the project's own code at runtime (see `docs/ART_BIBLE.md`).
